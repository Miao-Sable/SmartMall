# 智慧购物 H5

> 扫码即分析，让商品适不适合你一眼可见。

一款辅助购物的 H5 应用。用户扫描商品条形码或二维码后，应用获取商品信息，并结合个人过敏源、饮食偏好与消费历史，给出过敏提醒、成分分析、匹配度评分、价格趋势和个人消费仪表板。

**开发模式**：个人开发  
**当前版本**：v0.2（MVP 核心闭环）  
**技术栈**：Vue3 + Vant + FastAPI + SQLite/PostgreSQL

---

## 📌 需求目标

### 用户目标
- 扫码后快速获得商品基础信息。
- 自动识别商品是否包含个人过敏源。
- 根据个人偏好给出商品匹配度评分。
- 查看成分表、营养信息和历史价格趋势。
- 在首页查看个人扫描统计、过敏警报、消费趋势。

### 产品目标
- 完成一个可演示、可部署、可写进简历的 H5 MVP。
- 跑通“注册登录 → 设置档案 → 扫码 → 商品分析 → 仪表板”核心闭环。
- 架构可扩展，后续可接入真实 API、社区、比价等能力。

### 学习目标
- 掌握 Vue3 H5、扫码、图表、FastAPI、数据库、接口联调、部署。
- 学会用 MVP 思维控制范围，不追求大而全。

## 🛒 应用场景

1. **超市货架前**：扫描商品条码，立刻看到是否含过敏源。
2. **家中整理**：扫描已有商品，查看成分和营养信息。
3. **购买决策**：扫描后查看该商品与个人档案的匹配度评分。
4. **价格判断**：查看某商品历史价格趋势，判断是否值得购买。
5. **健康管理**：在首页查看最近扫描了多少商品、过敏警报分布、消费趋势。
6. **社区互动**（v1.1 后置）：在社区中查看他人评价或提出简单问题。

## 📋 业务规则

### 过敏提醒规则
- 用户档案中的过敏源与商品成分表做关键词匹配。
- 命中过敏源：高危提醒 + 成分高亮。
- 未命中：显示“未发现已知过敏源”，并展示免责声明。

### 匹配度评分规则（0-100 分）
- 基础 100 分。
- 命中过敏源：扣 50 分，标记“不推荐”。
- 不符合饮食偏好：每项扣 10 分。
- 最终等级：
  - 90-100：非常适合
  - 70-89：比较适合
  - 50-69：一般
  - 0-49：不适合

### 扫描历史规则
- 每次成功扫码或手动输入后保存记录。
- 记录包含：商品名、条码、时间、过敏风险、匹配度。
- 重复扫描按时间倒序保存，不覆盖。

### 商品数据规则
- MVP 使用本地 mock JSON。
- 预留第三方 API 接口位置。
- 查不到商品时提示“暂无数据”，引导手动输入。

### 权限与隐私
- 未登录：可看首页，不可扫码和保存历史。
- 已登录：可扫码、设置档案、查看历史。
- 过敏源和饮食偏好加密存储，不公开。

## 🚧 边界限制

### 功能边界
- 不做支付、下单、电商跳转。
- 不做医疗诊断。
- 不做复杂社交系统。
- 不做实时比价。
- 不做 AI 图像识别。
- 不保证覆盖所有商品。

### 技术边界
- H5 扫码优先支持微信内置浏览器、Safari、Chrome。
- 第三方商品 API 先不接，先用 mock。
- 短信验证码先不接真实服务。
- 历史价格先模拟。

### 合规边界
- 必须加免责声明：
  > 本应用提供的过敏提醒和成分分析仅供参考，不构成医疗建议。请以商品包装说明和医生意见为准。
- 需提供简单隐私说明。

## 🚀 快速开始

### 环境要求

- Node.js >= 18
- Python >= 3.10
- pnpm / npm / yarn
- SQLite（开发默认）

### 前端启动

```bash
cd frontend
npm install      # 或 pnpm install / yarn
npm run dev
```

### 后端启动

```bash
cd backend

# 1. 创建虚拟环境（仅首次）
python -m venv venv

# 2. 安装依赖（仅首次）
venv\Scripts\python -m pip install -r requirements.txt

# 3. 启动（推荐：无需激活环境，直接用虚拟环境的 python）
venv\Scripts\python -m uvicorn main:app --reload

# 或者：先激活虚拟环境，再用 uvicorn 命令（按终端选一种）
#   Git Bash:    source venv/Scripts/activate
#   CMD:         venv\Scripts\activate.bat
#   PowerShell:  .\venv\Scripts\Activate.ps1
#     （PowerShell 若报“运行脚本被禁用”，先执行：
#      Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass）
#   然后:        uvicorn main:app --reload
```

### 访问地址

- 前端：`http://localhost:5173`
- 后端 API 文档：`http://localhost:8000/docs`

## ❓ 常见问题

**Q：需要真实的商品 API 吗？**  
A：MVP 阶段先用本地 mock 数据，后续可接入阿里云、聚合数据等。

**Q：短信验证码怎么处理？**  
A：个人开发版先用邮箱注册或固定测试验证码，避免短信服务费用。

**Q：社区模块什么时候做？**  
A：放到 v1.1，优先保证核心扫码分析闭环。

**Q：如何部署？**  
A：前端 Vercel/Netlify，后端 Render/Railway，数据库 Supabase/Neon。
